# SQL Hospital Database Exercises

## About This Project

This repository contains a collection of SQL exercises using a Hospital database. These exercises are part of my Data Analytics learning journey and focus on developing fundamental SQL querying and data manipulation skills.

## Project Objectives

- Practice retrieving data from relational databases.
- Apply filtering conditions to extract specific records.
- Work with missing and non-missing values.
- Perform basic data manipulation.
- Develop a foundation for data analysis using SQL.

## SQL Skills Practiced

- **SELECT & FROM:** Retrieving data from tables.
- **WHERE:** Filtering records based on conditions.
- **IS NULL / IS NOT NULL:** Handling missing values.
- **LIKE:** Pattern matching and text filtering.
- **UPDATE & SET:** Modifying existing records.
- **CONCAT:** Combining text columns.
- **COUNT:** Counting records.
- **YEAR:** Extracting the year from date values.
- **IN:** Filtering records using multiple values.
- **AND:** Combining multiple conditions.
